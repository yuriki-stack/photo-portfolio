# YU Photography

写真ポートフォリオサイトの初期版です。

## ファイル構成

- `index.html` : サイト本体
- `style.css` : デザイン
- `script.js` : カテゴリ絞り込み・写真拡大
- `images/` : 公開用写真

## 写真を追加する方法

1. `images/` に写真を入れる
2. `index.html` の Gallery に写真カードを追加
3. `data-category` を `cat / landscape / city / nature` などに設定
4. GitHubへアップロードするとサイトを更新できます

## GitHub Pages

GitHubのリポジトリにこのフォルダの中身をアップロードし、Settings → Pages から公開設定を行ってください。
